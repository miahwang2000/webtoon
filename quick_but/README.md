# 수업용 퀵 런처

미니 매크로 키보드(또는 화면 클릭)로 자주 쓰는 수업 사이트를 즉시 여는 웹앱입니다.
버튼 정보는 코드에 없고 전부 구글 스프레드시트에서 불러옵니다.

## 1. 구글 스프레드시트 만들기

새 스프레드시트를 만들고 첫 번째 행에 아래 4개 열 이름을 정확히 입력하세요.

| 번호 | 이름 | URL | 아이콘 |
|---|---|---|---|
| 1 | 네이버 | https://naver.com | 🟢 |
| 2 | 구글 | https://google.com | 🔵 |
| 3 | 네이버 마이박스 | https://mybox.naver.com | 📦 |
| 4 | 블루킷 | https://www.blooket.com | 🎮 |
| 5 | 패들렛 | https://ko.padlet.com | 📌 |
| 6 | 웹툰 클래스 | https://miahwang2000.github.io/webtoon | 🎨 |

- **아이콘** 열은 비워둬도 됩니다. 비워두면 이름의 첫 글자가 대신 표시됩니다.
- 행을 추가하면 버튼도 자동으로 늘어납니다 (7번, 8번 …). 순서는 번호 기준으로 정렬됩니다.

## 2. 시트를 "링크가 있는 모든 사용자 - 뷰어"로 공유

오른쪽 위 **공유** 버튼 → 일반 액세스를 **"링크가 있는 모든 사용자"**, 권한은 **뷰어**로 설정하세요.
(파일 → 웹에 게시는 하지 않아도 됩니다.)

## 3. 시트 ID를 index.html에 붙여넣기

주소창 URL이 다음과 같은 형태입니다.

```
https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit#gid=0
                                      └────────── 이 부분이 SHEET_ID ──────────┘
```

`index.html` 파일을 열어 상단 `CONFIG` 부분을 찾아 값을 바꿉니다.

```js
const CONFIG = {
  SHEET_ID: "1AbCdEfGhIjKlMnOpQrStUvWxYz",  // 여기에 본인 시트 ID
  GID: "0",                                   // 탭이 여러 개면 해당 gid 숫자로 변경
  ...
};
```

## 4. GitHub Pages에 배포

`index.html`을 원하는 저장소(예: `miahwang2000.github.io`의 하위 폴더)에 올리면 바로 동작합니다.
서버나 별도 API 키가 필요 없습니다.

## 5. 미니 매크로 키보드와 연결하기

미니 키보드가 숫자키 **1~6**을 입력하도록 매크로를 설정하면, 웹앱이 켜져 있는 상태에서
키를 누르는 즉시 해당 번호의 사이트가 새 탭으로 열립니다. (화면의 버튼을 손으로 눌러도 동일하게 동작합니다.)

## 참고

- 시트 내용을 수정하면 웹앱을 **새로고침(또는 다시 열기)** 할 때 자동으로 반영됩니다.
- 인터넷 연결이 안 되거나 시트를 불러오지 못하면 오류 화면과 "다시 시도" 버튼이 표시됩니다.
- 관리자 페이지는 없습니다 — 스프레드시트가 곧 관리자 화면입니다.
