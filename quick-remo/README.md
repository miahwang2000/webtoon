# 퀵 런처 — 리모컨 버전

미니 매크로 키보드에 **Ctrl+Alt+1 ~ Ctrl+Alt+6**을 등록해서 누르면,
이 창이 활성화되어 있을 때 정해진 사이트가 새 탭으로 즉시 열립니다.

## 왜 "리모컨"인가

이 웹페이지는 TV 리모컨의 수신부와 같습니다. **이 창이 화면에서 활성화(포커스)되어 있을 때만**
미니 키보드의 신호(Ctrl+Alt+숫자)를 받을 수 있어요. 브라우저 보안 정책상 다른 프로그램이나
다른 탭을 보고 있을 때는 키 입력을 감지할 수 없습니다.

## 사용 방법

1. `index.html`을 GitHub Pages에 올립니다.
2. 브라우저에서 처음 접속하면 안내 화면이 뜹니다. **"리모컨 창 열기"** 버튼을 누르세요.
3. 화면 왼쪽에 작은 창(가로 280px, 세로 화면 전체)이 새로 뜹니다. 이 창을 화면 왼쪽에 그대로 두세요.
4. 미니 매크로 키보드에 아래처럼 단축키를 등록하세요.
   - 첫 번째 칸 → `Ctrl+Alt+1`
   - 두 번째 칸 → `Ctrl+Alt+2`
   - 세 번째 칸 → `Ctrl+Alt+3`
   - … 여섯 번째 칸까지 `Ctrl+Alt+6`
5. 리모컨 창을 한 번 클릭해서 활성화한 뒤, 미니 키보드를 누르면 해당 사이트가 새 탭으로 열립니다.
   (리모컨 창의 목록을 마우스로 직접 클릭해도 동일하게 작동합니다.)

## 투명도 조절

리모컨 창 아래쪽에 작은 슬라이더가 있어요. 드래그하면 패널 전체가 반투명해지고,
마지막으로 설정한 값은 브라우저에 저장되어 다음에 열 때도 그대로 유지됩니다.
창을 열면 처음엔 완전히 투명한 상태에서 설정해둔 투명도까지 서서히 나타나요.

> 참고: 이건 페이지 안의 요소(패널)를 반투명하게 만드는 것이고, 브라우저 창 자체가
> 데스크톱 배경까지 비치는 진짜 투명 창이 되는 건 아니에요. 이건 일반 웹페이지가
> 만들 수 없는 OS 수준의 기능이라서요.

## 알아두실 점

- **창 위치/크기는 처음 열 때만 지정**됩니다. 브라우저가 팝업을 차단하면 안내 문구가 뜨니,
  주소창의 팝업 차단 아이콘을 눌러 허용해 주세요.
- 사이트 목록은 **버전1과 동일한 고정 스프레드시트**를 그대로 사용합니다. (시트 ID가 코드에 이미 들어있어요.)
- 목록에 있는 항목 수만큼 `Ctrl+Alt+1`부터 순서대로 자동 매칭됩니다. (최대 9개까지 지원, 지금은 6개로 운영)
- 나중에 "직접 시트 링크 입력" 방식(버전2 방식)으로 바꾸고 싶으시면 말씀해 주세요 — 지금 구조에 그대로 얹을 수 있어요.

## 배포

`index.html` 파일 하나만 GitHub Pages에 올리면 바로 동작합니다. 서버나 API 키가 필요 없습니다.
