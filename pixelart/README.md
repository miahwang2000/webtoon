# 픽셀아트 클래스 — 버전 3 (MVP)
> v1(초판)·v2(우주/갤러그)에 이어지는 세 번째 버전입니다. 주제는 **음식 그리기**가
> 추가됐고, 미니게임은 **키오스크 주문 + 거스름돈 계산 퀴즈**로 완전히 새로
> 만들었습니다(액션 게임이 아니라 초등 수학과 연계되는 교육용 게임입니다).
> v1의 그림판 기능(도구, 가이드, 프레임, 제출 등)은 그대로 이어받았고, 프레임마다
> "메뉴 태그"를 붙이는 기능이 새로 추가됐습니다.

## 폴더 구조
```
pixelart/
├─ index.html                 (픽셀 아트 메이커, 이 파일만 있으면 실행됨)
├─ minigame.html               (픽셀 키오스크 — 주문+거스름돈 계산 퀴즈)
├─ classroom-input-guard.js   (기존 앱들과 공용으로 쓰시는 파일을 그대로 복사해 넣어주세요)
├─ icons/
│  └─ eraser.png, fill.png, zoom-in.png, zoom-out.png, zoom-reset.png
│     (지우개/채우기/확대/축소/100%보기 도구 아이콘 — 이미 포함되어 있음)
└─ guides/
   ├─ zodiac/   (주제: 12동물 이모티콘, 16·26칸 완성)
   ├─ misc/     (주제: 여러가지 이모티콘)
   └─ food/     (주제: 음식 그리기 — v3 신규, 아직 비어있음)
```
(v3는 "대표 프레임=주인공" 구조를 쓰지 않아서 `enemies/` 폴더가 없습니다.)

## 주제 & 난이도 & 파일명 규칙
- **주제 3가지**: "12동물 이모티콘"(zodiac) / "여러가지 이모티콘"(misc) /
  **"음식 그리기"(food, v3 신규)** — 시작 화면에서 학생이 선택합니다.
- 난이도: 초급 16×16 / 중급 26×26 / 고급 36×36 (파일명은 각각 `16_...png`,
  `26_...png`, `36_...png`)
- 가이드 파일은 `guides/{주제}/{난이도}_{이름}.png` 구조로 넣습니다.
- 한 주제·난이도 조합에 가이드를 여러 개 넣을 수 있습니다. `index.html`의
  `BUILTIN_GUIDES[주제][난이도]` 배열에 `{ id, label, src }` 한 줄만 추가하면
  갤러리에 자동으로 나타납니다.
- **음식 그리기 주제는 중급(26칸) 6종이 등록되어 있습니다**: 햄버거/치킨/콜라/
  감자튀김/오므라이스/김밥. 초급(16)·고급(36)은 아직 비어있습니다.
- **12동물 주제는 16·26칸이 완성되어 있고(8종: 돼지/뱀/호랑이/닭/개/말/양/원숭이),
  36칸은 비어있습니다.** (쥐·소·토끼·용 4종도 아직 없음)

## 🍔 메뉴 태그 (v3 신규 기능)
- 그림 그리기 화면에서 **"음식 그리기" 주제를 선택했을 때만** 나타납니다.
- 프레임 썸네일 오른쪽 아래에 작은 이모지 배지가 생기고, **탭할 때마다** 순서대로
  🍔 햄버거 → 🍗 치킨 → 🍙 김밥 → 🥤 콜라 → 🍟 감자튀김 → 🍳 오므라이스 → 🍽️ 기타
  순으로 바뀝니다.
  학생이 그림을 그린 뒤 어떤 메뉴인지 직접 골라주면 됩니다.
- 이 태그로 미니게임(키오스크)에서 이름과 가격이 정해집니다.

## 반영된 내용
- **"그림 그리기로" 버튼이 완전히 먹통이던 진짜 원인 발견 및 수정**: 지난 수정에서
  실수로 함수 선언 코드(`resumeDrawingUrl`, `goTo`)가 "🎨 나가기" 버튼의 클릭
  처리 블록 안쪽에 잘못 끼어 들어가 있었습니다. 그 바람에 그 함수들이 **다른
  버튼(완료 후 나가기, 확인 팝업, 뒤로가기 링크)에서는 아예 존재하지 않는 것으로
  취급**되어, 눌러도 조용히 아무 반응이 없었던 것이었습니다(전체화면 여부와는
  무관한 문제였습니다). 함수 선언을 올바른 위치로 꺼내서 모든 "그림 그리기로
  돌아가기" 버튼이 다시 정상 작동합니다.
- **메뉴 선택 화면에서 거스름돈 퀴즈 정답이 미리 보이던 문제 수정**: 메뉴를 고르는
  동안 "남은 돈"(예산−총액)을 보여주고 있었는데, 이 값이 결제 단계 퀴즈의 정답과
  똑같아서 계산 없이도 정답을 알 수 있었습니다. 이제 메뉴 선택 화면에는 예산만
  표시되고, "남은 돈"(정답)은 결제 단계에서 직접 맞혀야 확인할 수 있습니다.
- **모바일 최적화 재점검**: 작은 화면(아이폰 SE 등 320~360px 너비)에서 가로로
  넘치던 요소들을 찾아 고쳤습니다.
  - 그림 그리기 입장 카드(360px 고정)와 난이도 선택 창(440px 고정)이 좁은
    화면에서 화면 밖으로 삐져나가던 문제 → 화면 폭에 맞춰 줄어들도록 수정.
  - 음식 전달 화면의 쟁반(280px 고정)이 좁은 화면에서 넘치던 문제 → 화면 폭에
    맞춰 줄어들되, 넓은 화면에서는 영수증과 나란히 배치되는 모양은 그대로 유지.
  - 장바구니의 "빼기" 버튼과 HUD의 전체화면·나가기 버튼이 터치하기엔 너무
    작았던 문제 → 터치 영역을 넉넉하게 키움.
  - 혹시 모를 가로 넘침에 대비해 화면 전체에 안전장치(overflow-x 차단)도 추가.
- **화면 설명용 안내 알림창(토스트) 제거**: 음식 그리기 주제 진입 시 뜨던
  "가이드를 고르면 메뉴가 자동으로 정해져요..." 같은 기능 설명용 팝업을
  없앴습니다. 입력 오류 안내, 저장/제출 완료, 개수 제한처럼 **동작 결과를
  알려주는 알림**은 그대로 유지됩니다.
- **게임 완료 후 "그림 그리기로" 버튼이 반응 없던 문제 수정**: 전체화면 상태에서
  일부 브라우저(특히 모바일)가 화면 이동 자체를 조용히 막아버리는 경우가 있어서,
  이제 그림 그리기로 돌아가는 모든 버튼이 **먼저 전체화면을 확실히 끈 뒤** 이동
  하도록 방어 코드를 추가했습니다.
- **예산 안내 화면을 없애고 시작 화면에 통합**: 별도의 "오늘의 예산" 화면 없이,
  "게임 시작" 버튼이 있는 시작 화면에서 바로 "💰 예산은 ○○원이에요. 예산이
  충분하지 않다면 그림그리기에서 예산을 충전하세요."를 보여줍니다. 시작
  화면에는 이미 "🎮 게임 시작"(주문하기)과 "← 그림 그리기로 돌아가기"가 함께
  있어서 두 메뉴 모두 이 화면에서 바로 선택할 수 있습니다.
- **주제별로 저장 공간(세션)을 분리**: 지금까지는 학생 한 명당 저장 키가 하나뿐이라,
  어떤 주제를 선택하든 "이어서 그리기"를 누르면 항상 가장 최근에 작업한 주제
  그림으로 연결되는 문제가 있었습니다. 이제 저장 키에 **주제**가 포함되어서
  (`반_이름_주제`), 12동물/여러가지/음식 그리기가 서로 독립된 별도의 작품으로
  각각 저장·이어그리기됩니다. (⚠️ 저장 키 형식이 바뀌어서, 이 업데이트 이전에
  저장된 작품은 새 키로 자동 이전되지 않습니다 — 실제 학생 데이터가 쌓이기 전에
  적용하시는 걸 권장드립니다.)
- **게임 중간에 "그림 그리기로" 나가면 입장 화면이 아니라 그리던 화면으로 바로
  복귀**: 지금까지는 게임에서 나가면 항상 이름/반 선택하는 입장 화면부터
  다시 시작해야 했는데, 이제 예산 안내·메뉴 주문·결제 등 **게임을 끝내지 않고
  중간에 나가는 경우** 바로 원래 그리던 캔버스 화면으로 돌아갑니다(이어서 그리기
  잠금 규칙은 그대로 유지 — 게임을 끝까지 마친 뒤 나가는 경우는 입장 화면에서
  "새로 시작"만 가능하도록 정상적으로 안내됩니다).
- **"기타" 메뉴 이름 직접 입력 기능 제거**: 이제 "기타"로 그린 프레임은 전부
  이름이 그냥 "기타"로 표시됩니다(가격 4,000원으로 조정). 가이드 갤러리의
  "🍽️ 기타로 그리기" 선택지로 자유롭게 그리는 흐름은 그대로 유지됩니다.
- **음식 그리기는 한 번에 최대 6개까지**: 프레임을 7개 이상 만들려고 하면 안내
  토스트가 뜨고 막힙니다(프레임 추가·복제 버튼 모두 적용).
- **전달 화면 쟁반을 3열×2행 그리드로 재구성**: 최대 6개 메뉴 기준으로 크기와
  간격을 조정해서 가지런히 담기도록 했습니다.
- **영수증에서 이모티콘 제거**: 메뉴판·장바구니의 이모지는 그대로 두고,
  영수증(결제 화면/전달 화면 모두)에는 글자만 나오도록 했습니다.
- **가이드 갤러리에 "🍽️ 기타로 그리기" 선택지 복구**: 가이드 이미지가 6종(참고
  그림이 있는 메뉴)만 등록돼 있다 보니, 메뉴에 없는 걸 그리려는 "기타" 항목으로
  갈 방법이 없어졌던 문제를 고쳤습니다. 이제 가이드 갤러리 목록 끝에 있는
  "기타로 그리기" 타일을 누르면 가이드 없이 자유롭게 그릴 수 있고, 그 프레임의
  메뉴 태그가 자동으로 "기타"로 설정됩니다.
- **영수증 디자인 변경**: 흰 배경 + 검정 점선 테두리로 바꾸고, 맨 위에 "영수증"
  제목을 넣었습니다. 음식 전달 화면에서는 **쟁반 옆에 나란히**, 폭은 좁고
  세로로 긴 모양으로 배치했습니다.
- **가이드 그림 기본 투명도를 더 낮춤**(45% → 25%): 캔버스 위에 겹쳐 보이는 가이드가
  그림을 덜 가리도록 처음부터 더 연하게 보이게 했습니다.
- **메뉴 태그를 "고른 가이드 그림" 기준으로 자동 적용**: 학생은 정해진 순서대로
  그리지 않고 원하는 가이드를 골라서 그리기 때문에, 프레임 순서로 메뉴를 추측하는
  방식은 부정확했습니다. 이제 **가이드 갤러리에서 그림(예: 치킨)을 고르는 순간**,
  지금 그리고 있는 프레임의 메뉴 태그가 자동으로 그 메뉴로 맞춰집니다. 직접 그린
  이미지를 올렸을 때처럼 자동 판별이 안 되는 경우에만 프레임 아래 아이콘을 눌러서
  수동으로 골라주면 됩니다.
- **주문 메뉴가 전부 햄버거로 나오던 버그 수정**: 새 프레임을 추가할 때 항상
  "햄버거"(메뉴 목록의 첫 번째 항목)로만 기본 태그가 설정되던 게 원인이었습니다.
  이제 새 프레임을 추가하면 메뉴 태그가 순서대로 골고루 자동 배정됩니다(그래도
  프레임 아래 아이콘을 눌러 언제든 원하는 메뉴로 직접 바꿀 수 있어요). 음식 그리기
  주제를 선택하면 이 아이콘을 눌러보라는 안내 문구도 함께 뜨도록 했습니다.
- **음식 전달 화면 개선**: 쟁반과 그 위 음식 그림을 기존보다 20% 크게 표시하고,
  쟁반 아래에 주문 품목과 총액이 담긴 **영수증**을 함께 보여줍니다.
- **롱프레스가 다시 글자 선택으로 인식되던 문제 재수정**: 전체화면/나가기/확인
  팝업처럼 나중에 추가한 버튼들에 개별적으로 방지 처리를 빠뜨렸던 게 원인이었습니다.
  이제 버튼 전체에 한 번에 적용되는 전역 방어 로직으로 바꿔서, 앞으로 버튼을
  추가해도 이 문제가 재발하지 않습니다.
- **빈 프레임이 적 캐릭터로 잘못 등록되던 버그 수정**: 프레임을 추가만 하고 아무것도
  그리지 않으면, 그 빈 프레임이 미니게임에서 투명한(안 보이는) 적으로 등록되던
  문제가 있었습니다. 이제 빈 프레임은 만들지 않은 것과 동일하게 취급되어 적 캐릭터
  후보에서 제외됩니다.
- **그림 그리기에서 뒤로가기 시 게임 화면으로 돌아가던 문제 수정**: 미니게임에서
  그림 그리기로 나갈 때 브라우저 히스토리에 게임 화면이 남아있어서, 뒤로가기를
  누르면 다시 게임 화면으로 돌아가는 문제가 있었습니다. 이제 게임 화면 기록이
  남지 않도록 처리해서, 뒤로가기를 누르면 입장 화면으로 이동합니다.
- **"처음 화면" 버튼 동작 변경**: 원본 100% 크기가 아니라, **앱을 처음 열었을 때
  화면에 맞춰 자동 계산됐던 배율**로 돌아가도록 바꿨습니다 (작은 화면에서 100%로
  돌아가면 오히려 화면 밖으로 넘치는 문제를 방지).
- **주제명 변경**: "12간지 띠별 이모티콘" → **"12동물 이모티콘"**으로 변경했습니다.
- **12동물 초급(16칸) 가이드 추가**: 돼지/뱀/호랑이/닭/개/말/양/원숭이 8종을
  16칸용으로도 추가했습니다 (26칸에 이어 16칸도 완성, 36칸은 아직 없음).
- **게임이 멈추는 현상 방지**: 미니게임 화면 갱신 루프 안에서 예상치 못한 오류가
  하나라도 발생하면, 그 오류 때문에 화면 갱신 자체가 영영 멈춰버려서(캐릭터·버튼이
  반응 없는 "먹통" 상태) 겉보기엔 알 수 없는 오류처럼 보일 수 있는 구조적인 위험이
  있었습니다. 이제 매 프레임을 오류 방어 처리로 감싸서, 오류가 나도 그 프레임만
  건너뛰고 게임은 계속 진행되도록 했습니다.
- **돋보기(확대/축소/100%보기)·지우개 아이콘을 전달해주신 이미지로 교체**했습니다
  (기존 SVG로 직접 그린 돋보기 대신 실제 그려주신 픽셀아트 아이콘 사용).

## ⚙️ 저사양 태블릿 성능 최적화
사양이 낮은 기기에서도 부드럽게 동작하도록 다음을 가볍게 만들었습니다.
- **스테이지 테두리(줄무늬/체크/도트)를 매 프레임 다시 그리지 않고 캐싱**합니다.
  테두리는 스테이지 중에는 바뀌지 않는 그림이라, 스테이지가 바뀔 때 딱 한 번만
  그려서 저장해두고 이후에는 그 이미지를 그대로 재사용합니다.
- 스캔라인 효과에서 무거운 블렌드 연산(`mix-blend-mode`)을 제거했습니다.
- 조작 버튼의 흐림 효과(`backdrop-filter`)를 제거하고 배경을 살짝 진하게 해서
  시각적으로는 비슷하지만 GPU 부담은 줄였습니다.

## 🎮 미니게임 (minigame.html) — 픽셀 키오스크 (주문 + 거스름돈 계산 퀴즈)
- v1/v2와 게임 성격이 완전히 다릅니다. 액션 게임이 아니라 **키오스크에서 음식을
  주문하고 거스름돈을 계산하는 교육용 퀴즈**입니다(초등 수학 "거스름돈 계산"
  단원과 연계하기 좋습니다).
- **대표 프레임(★) 개념을 쓰지 않습니다.** 학생이 그린 프레임(빈 프레임 제외)이
  전부 메뉴판 항목이 됩니다. 각 프레임에는 그림 그리기 화면에서 **메뉴 태그
  (🍔 햄버거 / 🍗 치킨 / 🍙 김밥 / 🥤 콜라 / 🍟 감자튀김 / 🍳 오므라이스 / 🍽️ 기타)** 를
  붙일 수 있고, 프레임 썸네일 오른쪽 아래 이모지 배지를 탭하면 순서대로 바뀝니다.
  **새 프레임을 추가하면 메뉴 태그가 자동으로 골고루 순환 배정**되어서(직접 바꾸지
  않아도) 전부 같은 메뉴로 나오는 일이 없습니다.
- 가격: 햄버거/치킨/김밥 5,000원 / 콜라 1,000원 / 감자튀김 2,000원 /
  오므라이스 7,000원 / 기타 4,000원 (필요하면 `minigame.html`의 `MENU_CATEGORIES` 배열에서 바로 수정
  가능합니다).
- **예산**은 학생이 그린 메뉴 개수에 비례합니다: 1개=5,000원 / 2개=10,000원 /
  3개=15,000원 / 4개=20,000원 ... (그림 개수 × 5,000원). 메뉴 선택 화면에
  "예산은 ○○원이에요. 예산이 충분하지 않다면 그림그리기에서 예산을 충전하세요."
  라는 안내가 항상 표시됩니다(그림을 더 그리면 예산이 늘어난다는 뜻).
- 진행 순서: **①메뉴 선택 → ②장바구니 → ③결제(거스름돈 퀴즈) → ④주문 완료 →
  ⑤음식 준비(카운트다운) → ⑥음식 전달(쟁반 위에 그림+영수증 올려서 전달)**
  - ①②: 메뉴판에서 그림을 눌러 장바구니에 담습니다. 예산을 넘는 조합은 담을 수
    없도록 자동으로 막습니다(카드가 흐리게 비활성화됨).
  - ③: 영수증 형태로 총액/예산을 보여주고, "거스름돈은 얼마일까요?" 4지선다
    퀴즈를 냅니다. **보기는 매번 정답을 기준으로 그 자리에서 자동 생성**됩니다
    (총액과 헷갈리는 값, 예산을 그대로 답하는 값, 정답±500/1,000/2,000원 등에서
    무작위로 3개를 뽑아 정답과 섞음) — 그림 조합이 아무리 다양해도 항상 자연스러운
    보기가 만들어집니다.
  - ④⑤⑥: 랜덤 주문번호와 함께 완료 메시지 → 3·2·1 카운트다운 → 장바구니에 담은
    그림들을 쟁반 위에 올려서 보여주고(기존보다 20% 크게 표시), 쟁반 아래에
    품목·총액이 담긴 영수증도 함께 보여줍니다.
- **주문 완료(음식 전달) 화면이 마지막 화면**입니다. 여기서 "🔄 다시 주문하기"
  (새로 한 판 더, 연속 플레이 제한 적용) 또는 "🎨 그림 그리기로" 버튼을 눌러
