# AR Character Studio (MVP)

초등학생용 WebAR 그림 창작 앱입니다. 서버 없이 정적 파일만으로 동작하며,
GitHub Pages에 그대로 올리면 바로 사용할 수 있습니다.

## 지금 들어있는 기능 (1~4단계)

- **시작 화면**: 이름 · 반 선택, 가이드 그림(고양이/공룡/로봇) 선택 → "수업 시작하기"
- **그리기**: 마커 · 색연필 · 에어브러시 · 채우기 · 지우개, 12색 팔레트, 브러시 크기 3단계, 되돌리기
- **살아나기**: 완성한 그림이 AR 화면에 캐릭터로 등장 (카메라 배경 + 캐릭터 오버레이 방식,
  마커/WebXR 불필요 → **아이패드 Safari 포함 모든 태블릿에서 동일하게 동작**)
- **터치 상호작용**: 한 번 터치=점프, 두 번 터치=회전, 길게 누르기=춤
- **먹이 주기**: 🍖 버튼 → 화면 탭 → 캐릭터가 이동해서 먹는 연출
- **사진 촬영**: 카메라 화면 + 캐릭터를 합성해 촬영, 로컬에 다운로드 저장
- **자동 저장 / 초기화**: 그리는 중 자동 저장되어 실수로 새로고침해도 이어서 작업 가능.
  "수업 시작하기"를 다시 누르면 이전 학생 기록은 초기화됩니다.

## 아직 없는 기능 (다음 단계)

- 영상 녹화 (5단계)
- 선생님 Cloudinary 제출 (6단계) — 지금은 사진을 기기에 다운로드하는 방식만 있습니다.
  Cloudinary cloud name과 unsigned upload preset을 알려주시면 다음 단계에서 바로 연동하겠습니다.
- 선생님 갤러리 (7단계), 영화관 모드 (8단계)

## 로컬에서 미리보기

브라우저 카메라 권한은 `https://` 또는 `localhost`에서만 동작합니다. 폴더 안에서:

```
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## GitHub Pages 배포

1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. 저장소 Settings → Pages → Branch를 `main`(또는 `gh-pages`) / `/root`로 설정합니다.
3. 발급된 주소로 접속하면 바로 사용 가능합니다 (HTTPS라서 카메라 권한도 정상 동작).

## 알아두면 좋은 점 (기술 메모)

- AR은 실제 3D 평면 인식이 아니라 **카메라 배경 위에 캐릭터를 얹는 방식**입니다.
  아이패드 Safari는 WebXR을 지원하지 않기 때문에, 모든 기기에서 동일하게 동작하도록
  일부러 이 방식을 택했습니다. 교육 목적(그리기→상호작용→촬영)에는 충분합니다.
- 채우기(버킷) 도구는 학생이 그린 선(가이드 라인) 안쪽만 채워지도록 만들어져 있습니다.
- 그림 데이터는 브라우저 localStorage에만 저장되며 외부로 전송되지 않습니다(Cloudinary 연동 전).
