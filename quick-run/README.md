# 퀵 런처 v2 — 누구나 자기 시트로 만드는 런처

버전1과 달리, 코드에 시트 ID를 미리 넣어두지 않습니다.
처음 접속한 사람이 화면에서 직접 자기 구글 시트 링크를 붙여넣어 자신만의 런처를 만듭니다.

## 동작 방식

1. **처음 접속** → 입장 화면이 뜹니다.
   - "템플릿 사본 만들기" 버튼으로 템플릿 시트를 자기 드라이브에 복사
   - 번호 / 이름 / URL / 아이콘 채워 넣기
   - 시트 공유 설정을 "링크가 있는 모든 사용자 - 뷰어"로 변경
   - 완성된 시트 주소를 입력창에 붙여넣고 "시작하기"
2. 입력한 링크가 정상적으로 열리면, **시트 ID(+gid)만** `localStorage`에 저장하고 바로 런처 화면으로 전환됩니다.
   - 시트의 실제 데이터는 저장하지 않고, 매번 새로 불러옵니다.
3. **다음 접속부터**는 저장된 시트 ID를 자동으로 불러와 입장 화면 없이 바로 런처가 뜹니다.
4. 화면 오른쪽 위 **"다른 시트 사용"** 버튼을 누르면 저장된 연결을 지우고 다시 입장 화면으로 돌아갑니다.

## 템플릿 시트

기본 템플릿 링크가 코드 안에 미리 들어있습니다.

```
https://docs.google.com/spreadsheets/d/1SGbtSQh-tUGrrSH82mWPJKefnstxisCd0fnyK9MiFb4/copy
```

이 템플릿의 공유 설정이 "링크가 있는 모든 사용자 - 뷰어"로 되어 있어야
외부 사용자가 "사본 만들기"를 누를 수 있습니다. (한 번만 설정하면 계속 유지됩니다.)

다른 템플릿으로 교체하고 싶다면, `index.html`에서 아래 부분의 파일 ID만 바꿔주세요.

```html
<a class="template-link" href="https://docs.google.com/spreadsheets/d/여기에_새_템플릿_ID/copy" ...>
```

## 배포

버전1과 마찬가지로 GitHub Pages에 `index.html` 하나만 올리면 바로 동작합니다.
서버, API 키, 별도 백엔드가 필요 없습니다.

## 참고

- 시트 링크가 접근 불가능한 경우(공유 설정 누락 등) 화면에 공유 설정 방법을 바로 안내합니다.
- 미니 매크로 키보드의 숫자 1~9 키로 즉시 실행하는 기능은 버전1과 동일하게 유지됩니다.
- 버전1(`index.html`, 고정 시트)과 버전2(이 파일, 사용자별 시트)는 서로 독립된 파일입니다. 필요에 따라 원하는 경로에 각각 배포하세요.
