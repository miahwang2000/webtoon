# 픽셀 아트 공방 (MVP)

## 폴더 구조
```
pixelart/
├─ index.html                 (픽셀 아트 메이커, 이 파일만 있으면 실행됨)
├─ minigame.html               (버블 몬스터 잡기 미니게임)
├─ classroom-input-guard.js   (기존 앱들과 공용으로 쓰시는 파일을 그대로 복사해 넣어주세요)
├─ guides/
│  ├─ 16_oval.png, 16_circle.png              (초급, 16×16용 — 이미 포함되어 있음)
│  ├─ 26_robot.png, 26_spaceship.png, 26_ghost.png    (중급, 26×26용 — 이미 포함되어 있음)
│  └─ 36_tiger01.png, 36_tiger02.png, 36_tiger03.png   (고급, 36×36용 — 이미 포함되어 있음)
└─ enemies/
   └─ enemy1.png, enemy2.png, enemy3.png   (미니게임 대체 적 이미지 — 이미 포함되어 있음: 로봇→우주선→유령 순서)
```

## 난이도 & 파일명 규칙
- 초급: 16 × 16 → 파일명 `16_...png`
- 중급: 26 × 26 → 파일명 `26_...png`
- 고급: 36 × 36 → 파일명 `36_...png`
- 한 난이도에 가이드를 여러 개 넣을 수 있습니다. `index.html`의 `BUILTIN_GUIDES`
  배열에 `{ id, label, src }` 한 줄만 추가하면 갤러리에 자동으로 나타납니다.
  (고급에는 이미 호랑이 가이드 3종이 들어가 있어요.)

## 반영된 내용
- 시작 화면: 이름 → 반 선택 → "수업 시작하기" → `classroom-input-guard.js`의
  `ClassroomInputGuard.enterKioskMode()`를 호출해 전체화면 진입 (파일이 없으면
  기본 `requestFullscreen()`으로 자동 대체됩니다. 실제 함수 이름이 다르면
  `index.html`에서 `window.ClassroomInputGuard.enterKioskMode` 부분만 바꿔주세요.)
- 난이도: 16×16(초급) / 26×26(중급) / 36×36(고급) 3단계 선택, 저장된 작품이
  있으면 "이어서 그리기" 버튼 노출
- 캔버스: 항상 흰 배경 + 선택한 칸 수만큼 정확한 격자선이 보이고, 그 위에
  그림을 그리면 격자를 덮으며 채워집니다. 격자는 화면에서만 보이고
  저장/제출 파일에는 포함되지 않습니다.
- 도구: 연필 / 지우개 / **채우기(버킷)** / 화면 이동, 실행취소·다시실행(최대 30단계), 전체 지우기
  - 채우기는 탭 한 번으로 같은 색으로 이어진 영역을 한 번에 채워줍니다.
  - **모바일 최적화**: 왼쪽 도구 버튼은 텍스트 없이 아이콘만 크게 표시해 폭을 줄였고
    (120px→60px), 오른쪽 색상/가이드 패널은 "▶/◀" 버튼으로 **접고 펼 수 있어서**
    접으면 캔버스가 훨씬 넓게 보입니다. 버튼을 빠르게 연타해도 글자 선택/복사 메뉴가
    뜨지 않도록 처리했습니다(이름 입력창 등 실제 텍스트 입력란은 정상적으로 선택 가능).
- 확대/축소: 8단계 (50%~500%), 이동 도구로 드래그 팬
- 가이드: 썸네일 갤러리에서 여러 가이드 중 하나 선택 + 내 이미지 업로드 가이드
  - 항상 회색조(흑백) + 반투명으로 표시되어 실제 색칠과 헷갈리지 않습니다.
  - "🧭 위치조정" 버튼으로 캔버스를 드래그해 위치를 맞출 수 있고, 크기 슬라이더
    양옆의 **−/+ 버튼으로 1%씩 미세 조정**도 가능합니다 (슬라이더 자체는 5% 단위).
    "↺ 초기화"로 위치/크기를 되돌릴 수 있고, 다른 가이드로 바꾸면 자동 초기화됩니다.
  - `guides/` 폴더에 파일이 없으면 해당 썸네일에 "○○ 없음"으로 표시되어
    앱이 깨지지 않습니다.
- 프레임: 추가 / 복제 / 삭제 / 전환, 프레임마다 ★ 로 "대표 프레임" 지정 가능
- 색상 팔레트: 스틱맨 클래스와 동일한 12색(흰색 대신 스킨톤 #ffcc99) + 무지개 컬러피커 (아이콘 자체가 무지개 그라데이션)
- 저장: 반+이름 별로 `localStorage` 자동 저장 (그리기/도구 변경마다 자동 저장,
  상단에 "✓ 저장됨" 표시)
- 불러오기: 상단 "불러오기" 버튼으로 저장된 프로젝트 다시 열기
- PNG 저장: 현재 프레임을 배경 투명 PNG로 다운로드 (32px/칸 고해상도)
- 제출: **대표 프레임(★) 1장만** PNG로 Cloudinary에 업로드
  - `cloud_name: qmbonapf`, `upload_preset: stickman`
  - 저장 경로: `pixelart/{반}` 폴더, `context: student={이름}`
  - 나머지 프레임(미니게임용 애니메이션 소스)은 서버로 보내지 않고 `localStorage`에만 보관됩니다.

## ⚠️ 파일명은 항상 영문/숫자로
가이드·적 이미지 파일명에 한글을 쓰면(예: `16_타원.png`) GitHub Pages 배포 환경이나
브라우저에 따라 유니코드 인코딩 방식 차이로 파일을 못 찾는 경우가 있어서,
`16_oval.png`, `26_robot.png`처럼 **영문/숫자 파일명**으로 통일했습니다
(화면에 보이는 이름표는 그대로 한글로 표시됩니다). 앞으로 이미지를 추가하실 때도
파일명은 영문/숫자로 저장해 주세요.

## ⚙️ 저사양 태블릿 성능 최적화
사양이 낮은 기기에서도 부드럽게 동작하도록 다음을 가볍게 만들었습니다.
- **스테이지 테두리(줄무늬/체크/도트)를 매 프레임 다시 그리지 않고 캐싱**합니다.
  테두리는 스테이지 중에는 바뀌지 않는 그림이라, 스테이지가 바뀔 때 딱 한 번만
  그려서 저장해두고 이후에는 그 이미지를 그대로 재사용합니다.
- 스캔라인 효과에서 무거운 블렌드 연산(`mix-blend-mode`)을 제거했습니다.
- 조작 버튼의 흐림 효과(`backdrop-filter`)를 제거하고 배경을 살짝 진하게 해서
  시각적으로는 비슷하지만 GPU 부담은 줄였습니다.

## 다음에 확인하시면 좋은 것
1. `classroom-input-guard.js`를 실제로 복사해 넣고 함수 이름이 맞는지 한 번 실행 확인
2. Cloudinary `pixelart/{반}` 폴더가 실제로 잘 쌓이는지 제출 테스트 1회

## 🎮 미니게임 (minigame.html) — 버블 몬스터 잡기
- `index.html` 상단의 "🎮 미니게임" 버튼을 누르면 현재 학생의 이름/반 정보를 담아
  `minigame.html?class=..&name=..`로 이동합니다.
- **대표 프레임(★)에 그림이 하나도 없으면 이동하지 않고 경고 메시지를 띄웁니다**
  ("대표 캐릭터에 그림이 없어요! 먼저 그림을 그려주세요"). `minigame.html`에 직접
  접속한 경우에도 같은 검사를 한 번 더 해서, 비어있으면 시작 화면에 오류 안내와
  함께 이미지 업로드 옵션을 보여줍니다.
- **대표 프레임(★) = 플레이어 캐릭터**, **나머지 프레임들 = 각각 하나의 적 캐릭터**로 자동
  사용합니다. 저장된 그림이 없으면 PNG를 직접 올려서도 플레이할 수 있습니다(이 경우 적은
  모두 대체 이미지로 채워집니다).
- 적 프레임이 스테이지 수(3개)보다 적으면 처음 프레임부터 반복해서 재사용합니다.
  (프레임이 1개=대표만 있으면 3스테이지 모두 같은 대체 적을 사용)
- **적 프레임이 하나도 없을 때 사용할 대체 이미지**: `enemies/enemy1.png` ~
  `enemy3.png` 3개를 넣어주세요. 파일이 없으면 코드로 그린 기본 몬스터로 자동
  대체되어 게임이 깨지지 않습니다.
- 캐릭터 색은 그대로 두고, **모든 캐릭터(플레이어+적)에 밝은 노랑 테두리**를 둘러서
  검정 배경 위에서 항상 잘 보이게 했습니다 (색상 반전 대신 외곽선 방식).
- 8비트 레트로 스타일: 검정 배경 + 네온 컬러(사이언/핑크/옐로우), 스캔라인 효과,
  Press Start 2P 픽셀 폰트.
- 조작:
  - 화면 위 **반투명 십자 방향키(⬆◀▶, 오른쪽)** + **🫧 거품 버튼(왼쪽 중앙)**이
    캔버스 위에 떠 있습니다 (키보드 화살표처럼 ⬆가 위, ◀▶가 아래 나란히 배치됨).
  - **캔버스 아무 곳이나 탭/클릭해도 거품이 나갑니다** (버튼 위를 누르면 그 버튼 동작만
    실행되고 거품은 중복 발사되지 않음).
  - 키보드: 방향키 좌/우/위(이동·점프), **스페이스바(또는 Z, X) = 거품 발사**.
  - 캐릭터 머리 위에 노란 화살표로 현재 바라보는 방향(거품이 나갈 방향)을 표시합니다.
  - 거품이 적을 실제로 감싸듯 크게 부풀어서 가두고, 다시 건드리면 하얀 링+반짝이는
    파티클과 함께 **터지는 효과**를 내며 점수를 얻습니다(몬스터 1마리 = 100점).
  - 일정 시간 안에 거품을 터뜨리지 못하면 적이 다시 풀려납니다.
  - 거품 없이 적과 직접 부딪히면 목숨이 1개 줄어듭니다.
  - 거품과 적이 겹칠 때 **거품이 적보다 위(앞)에 그려져서**, 반투명한 거품 막이 적을
    실제로 감싸 가둔 것처럼 보입니다.
- **적 잡기 외에 스테이지마다 아이템 3개**를 먹어서 추가 점수를 얻을 수 있습니다.
  - 보석(스테이지 테마 색) = 50점
  - **별 모양 특별 아이템**(스테이지당 1개, 반짝이며 회전) = 300점 — 확 티 나게 점수가 높은
    아이템이라 눈에 띕니다.
  - **물약**은 1·2스테이지에 각 1개씩 등장하며 먹으면 목숨이 1개 늘어납니다(최대 5개,
    기본 3개 시작이므로 3스테이지에 도달할 때쯤 최대 +2개까지 늘어날 수 있음).
    3스테이지에는 물약이 없어 마지막 관문은 실력으로 돌파합니다.
  - 아이템은 각 스테이지의 발판 위 정해진 자리에 고정되어 있습니다.
- **스테이지 클리어 보너스**: 해당 스테이지 적을 모두 잡으면 추가 점수를 주며,
  단계가 오를수록 보너스가 커집니다 — 1스테이지 클리어 +200점, 2스테이지 +400점,
  3스테이지(최종) +700점. 클리어 시 안내 문구에 획득한 보너스 점수가 함께 표시됩니다.
- 화면 크기는 **반응형**(PC에서는 화면 너비의 최대 94%, 최대 1100px까지 크게 표시되고,
  모바일 세로 화면 등 화면 높이가 좁은 경우에도 **비율이 깨지지 않게** 폭 계산식에
  높이 제한을 함께 반영했습니다). 조작 버튼과 안내 문구 글자 크기도 화면 크기에 맞춰
  자동으로 커지고 작아집니다.
- **가로 화면 전용**: 이 게임은 가로로 긴 화면에 맞게 만들어져서, 세로로 들고 있으면
  "화면을 가로로 돌려주세요" 안내가 전체 화면에 뜨고 게임이 가려집니다 (기기를
  가로로 돌리면 바로 게임 화면으로 돌아옴).
- **전체화면**: "게임 시작"을 누르면 전체화면으로 진입을 시도합니다(지원하지 않는
  기기/브라우저에서는 조용히 무시되고 그냥 진행됩니다). HUD 오른쪽의 "⛶" 버튼으로
  언제든 전체화면을 켜고 끌 수 있습니다. 이전에 있었던 "전체화면이 풀리면 하단
  버튼이 가려지는" 문제는, 화면 높이 계산을 CSS `vh`에만 맡기지 않고 JS가
  `resize`/`orientationchange`/`fullscreenchange` 이벤트마다 실제 뷰포트 높이를
  다시 계산해서 즉시 반영하도록 고쳐 해결했습니다.
- 방향키/거품 버튼을 빠르게 연타해도 글자가 선택되면서 복사 메뉴가 뜨는 문제가
  없도록 화면 전체의 텍스트 선택을 막아뒀습니다.
- 스테이지는 3개, 적 수는 **1단계 3마리 → 2단계 4마리 → 3단계 5마리**로 늘어나며,
  해당 스테이지 적을 모두 잡으면 다음 스테이지로 이동합니다.
- **스테이지마다 발판 배치와 테두리 색 테마가 다릅니다** (아케이드 게임의 스테이지별
  연출을 참고해 새로 디자인함): 1단계 피라미드형+주황 줄무늬 테두리, 2단계 계단형+
  핑크 체크 테두리, 3단계 넓게 퍼진 3단 구조+사이언 도트 테두리.
- 목숨은 3개로 시작(하트 표시), 0개가 되면 게임 오버 / 3스테이지를 모두 클리어하면
  게임 클리어 화면이 나옵니다.
- "다시하기"를 누르면 같은 캐릭터로 점수/목숨/스테이지가 초기화되어 새 게임이 시작됩니다.
