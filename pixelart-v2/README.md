# 픽셀아트 클래스 — 버전 2 (MVP)
> v1(픽셀아트 클래스 초판)에서 이어지는 두 번째 버전입니다. 주제는 **우주·로봇·
> 항공·미래지향 컨셉**이 추가됐고, 미니게임은 **갤러그 스타일 세로 슈팅**으로
> 새로 만들었습니다. v1의 그림판 기능(도구, 가이드, 프레임, 제출 등)은 그대로
> 이어받았습니다.

## 주제 & 난이도 & 파일명 규칙
- **주제 3가지**: "12동물 이모티콘"(zodiac) / "여러가지 이모티콘"(misc) /
  **"우주 로봇 이모티콘"(space, v2 신규)** — 시작 화면에서 학생이 선택합니다.
- 난이도: 초급 16×16 / 중급 26×26 / 고급 36×36 (파일명은 각각 `16_...png`,
  `26_...png`, `36_...png`)
- 가이드 파일은 `guides/{주제}/{난이도}_{이름}.png` 구조로 넣습니다
  (예: `guides/space/16_robot.png`).
- 한 주제·난이도 조합에 가이드를 여러 개 넣을 수 있습니다. `index.html`의
  `BUILTIN_GUIDES[주제][난이도]` 배열에 `{ id, label, src }` 한 줄만 추가하면
  갤러리에 자동으로 나타납니다.
- **12동물 주제는 16·26칸이 완성되어 있고(8종: 돼지/뱀/호랑이/닭/개/말/양/원숭이),
  36칸은 비어있습니다.** (쥐·소·토끼·용 4종도 아직 없음)
- **우주 로봇 주제는 아직 가이드 이미지가 하나도 없습니다.** 이미지를 주시면
  16/26/36칸에 등록해드릴게요.

## 반영된 내용
- **v1에서 발견된 버그들을 v2에도 동일하게 적용**:
  - 버튼을 길게 눌렀을 때 텍스트 선택/콜아웃 메뉴로 인식되던 문제를 앱 전체에
    적용되는 전역 방어 로직으로 수정.
  - 빈 프레임(그림을 그리지 않은 프레임)이 미니게임에서 투명한 적으로 잘못
    등록되던 버그 수정 — 이제 빈 프레임은 만들지 않은 것과 동일하게 처리됩니다.
  - 그림 그리기에서 뒤로가기를 누르면 게임 화면으로 돌아가던 문제 수정 — 이제
    뒤로가기를 누르면 입장 화면으로 이동합니다.
  - 이동/발사 버튼을 화면 맨 가장자리(2px)에서 살짝 안쪽(14px)으로 옮기고
    `touch-action:none`을 명시해서, 모바일 브라우저의 가장자리 제스처(뒤로가기 등)와
    충돌해 버튼이 잘 눌리지 않던 문제를 방지했습니다.
- **"처음 화면" 버튼 동작 변경**: 원본 100% 크기가 아니라, **앱을 처음 열었을 때
  화면에 맞춰 자동 계산됐던 배율**로 돌아가도록 바꿨습니다 (작은 화면에서 100%로
  돌아가면 오히려 화면 밖으로 넘치는 문제를 방지).
- **주제명 변경**: "12간지 띠별 이모티콘" → **"12동물 이모티콘"**으로 변경했습니다.
- **12동물 초급(16칸) 가이드 추가**: 돼지/뱀/호랑이/닭/개/말/양/원숭이 8종을
  16칸용으로도 추가했습니다 (26칸에 이어 16칸도 완성, 36칸은 아직 없음).
- **게임이 멈추는 현상 방지**: 미니게임 화면 갱신 루프 안에서 예상치 못한 오류가
  하나라도 발생하면, 그 오류 때문에 화면 갱신 자체가 영영 멈춰버려서(캐릭터·버튼이
  반응 없는 "먹통" 상태) 겉보기엔 알 수 없는 오류처럼 보일 수 있는 구조적인 위험이
  있었습니다. 이제 매 프레임을 오류 방어 처리로 감싸서, 오류가 나도 그 프레임만
  건너뛰고 게임은 계속 진행되도록 했습니다.
- **돋보기(확대/축소/100%보기)·지우개 아이콘을 전달해주신 이미지로 교체**했습니다
  (기존 SVG로 직접 그린 돋보기 대신 실제 그려주신 픽셀아트 아이콘 사용).
- **길게 눌러서 다른 도구를 고를 수 있는 버튼**(지우개/전체지우기, 확대/축소/
  100%보기)에는 **포토샵처럼 오른쪽 아래에 작은 삼각형 표시**를 넣어서, 숨겨진
  옵션이 있다는 걸 한눈에 알 수 있게 했습니다.
- **연필/채우기를 다시 독립 버튼으로 분리**했습니다 (자주 쓰는 도구라 롱프레스 방식이
  불편하다는 피드백 반영). 지우개/전체지우기, 확대/축소/100%보기는 이전처럼 롱프레스
  콤보로 유지됩니다.
- **지우개 아이콘에 연한 회색 테두리**를 추가해 배경과 더 잘 구분되도록 했습니다.
- **확대/축소/100%보기를 하나의 콤보 버튼으로 통합**했습니다. 짧게 누르면 마지막
  동작을 반복하고, 길게 누르면 팝업에서 확대·축소·100%보기 중 고를 수 있습니다.
- **롱프레스 팝업(플라이아웃) 개선**: 버튼에 **틈 없이 딱 붙어서** 뜨고(포토샵 도구
  팝업처럼), 크기도 글자 길이에 맞게 자동 조절되며, 그림자 효과는 없앴습니다.
- **하단 프레임 바가 세로로 밀리지 않도록 고정**했습니다(항상 가로로만 늘어나고,
  넘치는 부분은 손가락으로 밀어서 가로 스크롤). **▶ 이동 버튼**은 오른쪽에 더 볼
  프레임이 실제로 있을 때만 나타나서, 항상 떠 있는 버튼 때문에 "지금이 마지막
  프레임인가?" 헷갈리는 일이 없습니다 (◀는 혼란을 줄 수 있어 넣지 않았습니다).
  프레임을 추가/복제/전환할 때마다 현재 프레임이 자동으로 화면에 보이도록
  스크롤됩니다.
- **키보드 단축키**: `Ctrl+Z`(실행 취소), `Ctrl+Shift+Z`(다시 실행)를 지원합니다.
- 상단바 전체화면 버튼에 **"전체화면" 텍스트**를 함께 표시합니다.
- **시작 화면 위치를 위쪽으로 배치**해서, 모바일에서 키보드가 올라와도 이름 입력창과
  시작 버튼이 가려지지 않습니다.
- **왼쪽 도구 패널을 카테고리 구분 없이 한 줄로 정리**했습니다.
- **도구 버튼 3쌍을 롱프레스(길게 누르기) 콤보 버튼으로 통합**했습니다
  (포토샵의 도구 그룹처럼 동작):
  - ✏️ 연필 / 🧽 채우기 → 짧게 누르면 마지막에 쓴 도구 사용, 길게 누르면 작은
    팝업에서 선택
  - 🧽 지우개 / 🗑 전체 지우기 → 짧게 누르면 지우개, 길게 누르면 팝업에서
    "전체 지우기" 선택 가능
  - 🔍 확대 / 축소 / 100% 보기 → 짧게 누르면 마지막에 쓴 동작 반복, 길게 누르면
    팝업에서 셋 중 선택 (세로로 길었던 버튼 3개를 1개로 줄임, 아이콘은 렌즈 안에
    +/− 가 정확히 들어가는 SVG로 직접 그림)
- **모바일 화면 크기에 맞춰 시작 확대 배율을 자동으로 계산**합니다. 화면이 작으면
  처음부터 그림 전체가 한눈에 보이도록 자동으로 축소된 상태로 시작해서, 축소했다가
  다시 확대하는 불편이 없어졌습니다.
- **격자선이 축소 시 사라지던 버그 수정**: 격자를 낮은 고정 해상도로 그려두고
  CSS로 확대/축소하던 방식이라, 많이 축소하면 얇은 1px 선이 브라우저의 축소
  연산에서 통째로 건너뛰어지는 문제가 있었습니다. 이제 격자는 **항상 실제 화면
  픽셀 크기 그대로(1:1)** 다시 그려서, 아무리 축소해도 격자선이 사라지지 않습니다.
- **모바일 자동 맞춤 배율 버그 수정**: 화면이 아주 작아서 준비된 확대 단계(최소
  50%) 중 맞는 게 하나도 없을 때, 오히려 100%로 되돌아가 화면 밖으로 넘치던
  버그를 고쳐서 이제 그런 경우엔 가장 작은 단계(50%)로 시작합니다.
- **확대/축소 단계를 더 세밀하게** 조정했습니다(8단계 → 15단계, 50%~500%). 단계
  사이 간격이 줄어서 원하는 크기에 더 정확하게 맞출 수 있습니다.
- **전체화면이 자주 풀리던 문제 수정**: 네이티브 `confirm()` 창(새 작품/전체지우기/
  프레임 삭제/제출 확인)이 뜨면 브라우저가 전체화면을 자동으로 풀어버리는 문제가
  있었습니다. 전부 **직접 만든 확인창(팝업)** 으로 바꿔서, 확인창을 띄워도 전체화면이
  풀리지 않습니다.
- **게임을 끝까지 플레이한 후에만 이어서 그리기 불가**: 미니게임을 실행만 하고
  중간에 나가면 이어서 그리기가 그대로 가능하지만, **게임오버 또는 게임클리어까지
  실제로 도달하면** 해당 작품에 표시가 남아 그림 그리기로 돌아가도 "이어서 그리기"
  옵션이 더 이상 나오지 않고 새 작품만 시작할 수 있습니다.
- **시작 화면에서 "주제" 선택**: 이름/반과 함께 "12동물 이모티콘" 또는
  "여러가지 이모티콘" 중 하나를 고르고 수업을 시작합니다. 선택한 주제는 프로젝트에
  저장되어, 이어서 그리기를 해도 같은 주제의 가이드가 나옵니다.
- 상단바에 **"⛶" 전체화면 켜기/끄기 버튼**을 추가했습니다 (언제든 직접 켜고 끌 수 있음).
- **제출 전에는 "🎮 미니게임" 버튼이 비활성화**되어 있고, 제출을 완료해야 눌러집니다.
  (제출 여부는 프로젝트에 저장되어, 불러오기 해도 상태가 유지됩니다.)
- 지우개/채우기 도구 아이콘을 전달해주신 이미지로 교체했습니다.
- "이동(팬)" 도구를 확대/축소 버튼 바로 위로 옮겨서 화면 이동·확대 조작을 한 곳에
  모았습니다.
- 확대 후 화면을 이동(팬)할 때 바깥 배경이 어둡게 보이던 문제를 흰색 배경으로
  고쳤습니다.
- 시작 화면: 이름 → 반 선택 → "수업 시작하기" → `classroom-input-guard.js`의
  `ClassroomInputGuard.enterKioskMode()`를 호출해 전체화면 진입 (파일이 없으면
  기본 `requestFullscreen()`으로 자동 대체됩니다. 실제 함수 이름이 다르면
  `index.html`에서 `window.ClassroomInputGuard.enterKioskMode` 부분만 바꿔주세요.)
- 난이도: 16×16(초급) / 26×26(중급) / 36×36(고급) 3단계 선택, 저장된 작품이
  있으면 "이어서 그리기" 버튼 노출
- 캔버스: 항상 흰 배경 + 선택한 칸 수만큼 정확한 격자선이 보이고, 그 위에
  그림을 그리면 격자를 덮으며 채워집니다. 격자는 화면에서만 보이고
  저장/제출 파일에는 포함되지 않습니다.
- 도구: 연필 / 지우개 / **채우기(버킷)** / 화면 이동, 실행취소·다시실행(최대 30단계), 전체 지우기
  - 채우기는 탭 한 번으로 같은 색으로 이어진 영역을 한 번에 채워줍니다.
  - **모바일 최적화**: 왼쪽 도구 버튼은 텍스트 없이 아이콘만 크게 표시해 폭을 줄였고
    (120px→60px), 오른쪽 색상/가이드 패널은 "▶/◀" 버튼으로 **접고 펼 수 있어서**
    접으면 캔버스가 훨씬 넓게 보입니다. 버튼을 빠르게 연타해도 글자 선택/복사 메뉴가
    뜨지 않도록 처리했습니다(이름 입력창 등 실제 텍스트 입력란은 정상적으로 선택 가능).
- 확대/축소: 8단계 (50%~500%), 이동 도구로 드래그 팬
- 가이드: 썸네일 갤러리에서 여러 가이드 중 하나 선택 + 내 이미지 업로드 가이드
  - 항상 회색조(흑백) + 반투명으로 표시되어 실제 색칠과 헷갈리지 않습니다.
  - "🧭 위치조정" 버튼으로 캔버스를 드래그해 위치를 맞출 수 있고, 크기 슬라이더와
    양옆의 **−/+ 버튼 모두 2% 단위**로 통일해서 슬라이더로 대략 맞추고 버튼으로
    세밀하게 조정하기 쉽게 했습니다. 현재 크기(%)가 라벨로 실시간 표시되어
    조정이 실제로 적용되고 있는지 바로 확인할 수 있습니다.
    "↺ 초기화"로 위치/크기를 되돌릴 수 있고, 다른 가이드로 바꾸면 자동 초기화됩니다.
  - `guides/` 폴더에 파일이 없으면 해당 썸네일에 "○○ 없음"으로 표시되어
    앱이 깨지지 않습니다.
- 프레임: 추가 / 복제 / 삭제 / 전환, 프레임마다 ★ 로 "대표 프레임" 지정 가능
- 색상 팔레트: 스틱맨 클래스와 동일한 12색(흰색 대신 스킨톤 #ffcc99) + 무지개 컬러피커
  - PC/모바일 관계없이 항상 **자체 제작한 작은 팝업**이 떠서 색상/채도/명도 영역과
    무지개 띠를 눌러 바로 색을 고를 수 있습니다 (모바일에서 기기 기본 색상 선택
    화면으로 넘어가지 않습니다).
- 저장: 반+이름 별로 `localStorage` 자동 저장 (그리기/도구 변경마다 자동 저장,
  상단에 "✓ 저장됨" 표시)
- 불러오기: 상단 "불러오기" 버튼으로 저장된 프로젝트 다시 열기
- PNG 저장: 현재 프레임을 배경 투명 PNG로 다운로드 (32px/칸 고해상도)
- 제출: **대표 프레임(★) 1장만** PNG로 Cloudinary에 업로드
  - `cloud_name: qmbonapf`, `upload_preset: stickman`
  - 저장 경로: `pixelart/{반}` 폴더, `context: student={이름}`
  - 나머지 프레임(미니게임용 애니메이션 소스)은 서버로 보내지 않고 `localStorage`에만 보관됩니다.

## ⚠️ 파일명은 항상 영문/숫자로
가이드·적 이미지 파일명에 한글을 쓰면(예: `16_타원.png`) GitHub Pages 배포 환경이나
브라우저에 따라 유니코드 인코딩 방식 차이로 파일을 못 찾는 경우가 있어서,
`16_oval.png`, `26_robot.png`처럼 **영문/숫자 파일명**으로 통일했습니다
(화면에 보이는 이름표는 그대로 한글로 표시됩니다). 앞으로 이미지를 추가하실 때도
파일명은 영문/숫자로 저장해 주세요.

## ⚙️ 저사양 태블릿 성능 최적화
사양이 낮은 기기에서도 부드럽게 동작하도록 다음을 가볍게 만들었습니다.
- **스테이지 테두리(줄무늬/체크/도트)를 매 프레임 다시 그리지 않고 캐싱**합니다.
  테두리는 스테이지 중에는 바뀌지 않는 그림이라, 스테이지가 바뀔 때 딱 한 번만
  그려서 저장해두고 이후에는 그 이미지를 그대로 재사용합니다.
- 스캔라인 효과에서 무거운 블렌드 연산(`mix-blend-mode`)을 제거했습니다.
- 조작 버튼의 흐림 효과(`backdrop-filter`)를 제거하고 배경을 살짝 진하게 해서
  시각적으로는 비슷하지만 GPU 부담은 줄였습니다.

## 🎮 미니게임 (minigame.html) — 픽셀 스페이스 디펜더 (갤러그 스타일)
- `index.html` 상단의 "🎮 미니게임" 버튼을 누르면 현재 학생의 이름/반 정보를 담아
  `minigame.html?class=..&name=..`로 이동합니다.
- **대표 프레임(★) = 플레이어 우주선**, **나머지 프레임들 = 각각 하나의 적 캐릭터**로
  자동 사용합니다. 적 프레임이 스테이지 수(3개)보다 적으면 처음 프레임부터 반복
  재사용하고, 하나도 없으면 `enemies/enemy1.png` ~ `enemy3.png` 대체 이미지를
  사용합니다(아직 파일이 없으면 코드로 그린 기본 적 모양으로 자동 대체되어 게임이
  깨지지 않습니다 — **곧 전달해주실 예비 적 캐릭터 이미지를 이 자리에 넣으시면 됩니다**).
- 캐릭터 색은 그대로 두고 모든 캐릭터(플레이어+적)에 밝은 노랑 테두리를 둘러서
  검정 배경 위에서 항상 잘 보이게 했습니다.
- **이 게임은 세로 화면 전용**입니다. 가로로 들고 있으면 "화면을 세로로 돌려주세요"
  안내가 뜨고 게임이 가려집니다 (v1의 버블 몬스터 잡기는 반대로 가로 전용입니다 —
  두 미니게임의 방향이 다르니 헷갈리지 않게 주의해주세요).
- **난이도 선택(쉬움/보통)**: 시작 화면에서 "게임 시작"을 누르기 전에 고릅니다.
  - **쉬움**: 적이 대형을 유지한 채 좌우로만 움직입니다. 급강하 공격이 없어서
    부담 없이 사격 연습을 할 수 있습니다.
  - **보통**(기본 선택): 적이 대형에서 가끔 이탈해 아래로 급강하하며 공격합니다
    (갤러그 특유의 다이빙). 급강하 중인 적과 부딪히면 목숨이 줄어듭니다.
- 조작: **◀ ▶ 이동 + 🔫 발사** — 발사 버튼은 탭할 때마다 한 발씩 나갑니다(연사 아님,
  다만 너무 빠른 연타는 짧은 쿨타임으로 막습니다). 캔버스 화면을 탭해도 발사됩니다.
  키보드는 방향키(이동) + 스페이스바(발사)로도 테스트 가능합니다.
- 스테이지는 3개, 적 수는 **1단계 3마리 → 2단계 4마리 → 3단계 5마리**로 늘어나며,
  해당 스테이지 적을 모두 잡으면 다음 스테이지로 이동합니다. 스테이지마다 화면
  테두리 색 테마가 다릅니다(사이언 → 핑크 → 옐로우).
- 점수: 적 처치 1마리 = 100점, 스테이지 클리어 보너스는 1단계 +200점 → 2단계
  +400점 → 3단계 +700점으로 단계가 오를수록 커집니다.
- 목숨은 하트 3개로 시작(최대 5개), 급강하 적과 부딪히면 1개 감소, 0개면 게임
  오버 / 3스테이지를 모두 클리어하면 게임 클리어 화면이 나옵니다.
- v1과 동일하게 적용되는 공통 규칙:
  - **연속 플레이 제한**: 한 번 방문에서 최대 2번까지만 연속으로 플레이할 수
    있고, 3번째 시도하면 "그림을 더 그려볼까요?" 안내 화면으로 넘어갑니다.
  - **게임을 끝까지 플레이한 후에만 이어서 그리기 불가**: 중간에 나가면 이어서
    그리기가 가능하지만, 게임오버 또는 게임클리어까지 실제로 도달하면 해당
    작품은 "이어서 그리기"가 막히고 새 작품만 시작할 수 있습니다.
  - **게임 중 "그림 그리기로 나가기" 버튼**: HUD의 "🎨" 버튼 → 확인 팝업(전체화면
    유지) → 그림 그리기 화면으로 이동.
  - **전체화면**: 난이도를 고르는 순간부터 전체화면을 시도하고, HUD의 "⛶" 버튼으로
    언제든 켜고 끌 수 있습니다.
  - 델타타임 기반 이동으로 기기 화면 재생률(60/90/120Hz)과 무관하게 항상 같은
    속도로 움직이며, 화면 갱신 루프는 오류 방어 처리가 되어 있어 예상치 못한
    오류가 있어도 게임이 조용히 멈추지 않고 계속 진행됩니다.
