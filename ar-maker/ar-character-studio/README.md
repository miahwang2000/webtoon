# AR Character Studio (MVP)

초등학생용 WebAR 그림 창작 앱입니다. 서버 없이 정적 파일만으로 동작하며,
GitHub Pages에 그대로 올리면 바로 사용할 수 있습니다.

## 지금 들어있는 기능 (1~6단계 일부)

- **시작 화면**: 이름 입력, 8개 반(그룹) 중 선택, 가이드 그림(코끼리/사막여우/악어) 선택 → "수업 시작하기"
- **그리기**: 마커 · 색연필 · 에어브러시 · 채우기 · 지우개, 12색 팔레트, 브러시 크기 3단계, 되돌리기
- **살아나기**: 완성한 그림이 AR 화면에 캐릭터로 등장 — 등장 시 커지는 애니메이션 + 빛 효과 +
  점프 착지, 바닥 그림자, 위치에 따른 원근감(위=작게/아래=크게)까지 표현됩니다.
  카메라 배경 + 캐릭터 오버레이 방식이라 아이패드 Safari 포함 모든 태블릿에서 동일하게 동작해요.
- **터치 상호작용**: 한 번 터치=이동, 두 번 터치=점프, 길게 누르기=춤
- **먹이 주기**: 🍖 버튼을 누르면 즉시 먹이가 캐릭터에게 날아갑니다 (연타 가능)
- **사진 촬영 + 제출**: 카메라 화면 + 캐릭터를 합성해 촬영, **Cloudinary로 바로 제출**하거나
  기기에 다운로드할 수 있습니다.
- **자동 저장 / 초기화**: 그리는 중 자동 저장되어 실수로 새로고침해도 이어서 작업 가능.
  "수업 시작하기"를 다시 누르면 이전 학생 기록은 초기화됩니다.

| 드롭다운 표시명 | Cloudinary 폴더 |
|---|---|
| 신남초 돌봄A | AR/class_sdD_A |
| 신남초돌봄 B | AR/class_sdD_B |
| 신도림초 A | AR/class_sd_A |
| 신도림초 B | AR/class_sd_B |
| 등현초A | AR/class_dh_A |
| 등현초B | AR/class_dh_B |
| 신남초 A | AR/class_sn_A |
| 신남초 B | AR/class_sn_B |

Cloudinary 설정 (`js/cloudinary.js`): Cloud Name `qmbonapf`, Upload Preset `stickman` (unsigned).
제출된 사진은 `AR/{반코드}/{이름}_{반코드}_{타임스탬프}.png` 형태로 저장됩니다.

> Cloudinary Console에서 해당 unsigned preset이 `folder`/`public_id` 파라미터를
> 허용하도록 설정되어 있어야 위 폴더 구조대로 저장됩니다. (Settings → Upload →
> Upload presets → `stickman` 편집 → "Folder" 항목 확인)

## 아이콘

브러시 도구 아이콘은 지금은 이모지(🖊️✏️🌫️🪣🧽↩️)를 쓰고 있어요. 지우개처럼
정확히 맞는 이모지가 없는 경우도 있어서, 원하시는 아이콘 이미지를 주시면
`assets/icons/`에 넣고 이미지로 교체해드릴 수 있습니다.

## 로컬에서 미리보기

브라우저 카메라 권한은 `https://` 또는 `localhost`에서만 동작합니다. 폴더 안에서:

```
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## GitHub Pages 배포

1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. 저장소 Settings → Pages → Branch를 `main`(또는 `gh-pages`) / `/root`로 설정합니다.
3. 발급된 주소로 접속하면 바로 사용 가능합니다 (HTTPS라서 카메라 권한도 정상 동작).

## 알아두면 좋은 점 (기술 메모)

- AR은 실제 3D 평면 인식이 아니라 **카메라 배경 위에 캐릭터를 얹는 방식**입니다.
  아이패드 Safari는 WebXR을 지원하지 않기 때문에, 모든 기기에서 동일하게 동작하도록
  일부러 이 방식을 택했습니다.
- 채우기(버킷) 도구는 학생이 그린 선(가이드 라인) 안쪽만 채워지도록 만들어져 있습니다.
- 가이드 그림(JPG)은 흰 배경 + 검은 선으로 되어 있는데, 앱이 자동으로 흰 부분을
  투명하게 바꿔서 색칠 레이어 위에 항상 선이 보이도록 처리합니다.
- Cloudinary 제출은 Upload Preset이 "Unsigned"로 설정되어 있어야 합니다 (서버 키 없이
  브라우저에서 바로 업로드하기 때문입니다).
