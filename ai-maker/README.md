# 캐릭터 만들기 공방 (AI 캐릭터 메이커 MVP)

스케치 → AI 선화 → 채색 → 캐릭터 시트 → 제출까지 5단계로 진행하는 초등학생용 교육용 웹앱입니다.
바닐라 HTML/CSS/JS로 만들어져 있어 Stickman Class와 동일하게 GitHub Pages에 그대로 올릴 수 있어요.

## 파일 구성
- `index.html` – 전체 화면 구조 (5단계 스텝)
- `style.css` – 크레용/스케치북 테마 스타일
- `app.js` – 캔버스 드로잉, 채색, 캐릭터 시트, 저장/제출 로직
- `config.js` – **API 키 등 민감 정보** (⚠️ .gitignore에 포함됨, 공개 저장소에 올리지 마세요)

## 로컬에서 열어보기
```bash
cd character-maker
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
`file://`로 직접 열어도 대부분 동작하지만, 일부 브라우저는 `fetch`를 막을 수 있어 로컬 서버 실행을 권장해요.

## ⚠️ API 키 보안 — 배포 전 꼭 확인하세요
지금 `config.js`에는 말씀해주신 Gemini API 키가 그대로 들어있습니다. **이 상태로 GitHub Pages 같은 공개 정적 호스팅에 올리면, 학생 브라우저의 개발자 도구(네트워크 탭)에서 누구나 이 키를 그대로 복사해갈 수 있어요.** 무제한 사용이 가능한 키라면 도용당해 예상치 못한 비용이 청구될 수 있습니다.

권장 순서:
1. **당장 수업/테스트용**: 지금 상태로 로컬 또는 접근이 제한된 환경에서만 사용
2. **학급 배포용**: 서버리스 함수(Cloudflare Workers, Vercel Functions, Google Cloud Functions 등) 뒤에 키를 숨기고, `app.js`의 `callGeminiLineArt()`가 그 함수 주소를 호출하도록 한 줄만 바꾸면 됩니다. 필요하시면 이 프록시 코드도 만들어드릴게요.
3. Google AI Studio에서 이 키에 **일일 요청 한도**를 걸어두면 만일 유출되어도 피해를 줄일 수 있어요.

## AI 선화 생성 (STEP 2)
- 모델: `gemini-2.5-flash-image` (config.js에서 변경 가능)
- 스케치 이미지 + 프롬프트를 함께 보내 검정 선화로 변환합니다.
- API 오류/타임아웃(25초)/네트워크 오류/사용량 초과 시 **자동으로 로컬 추천 모드**로 전환됩니다. TensorFlow.js로 스케치의 선을 흑백으로 정리하고 굵게 다듬어 대체 선화를 만들기 때문에, 인터넷이 끊겨도 수업이 멈추지 않아요.
- AI 호출은 세션당 1번만 발생합니다 (지침 원칙 준수).

## 채색 (STEP 3)
- 캔버스를 터치하면 해당 영역을 Flood Fill로 채색합니다.
- 실행취소는 최근 15단계까지 지원합니다.

## 캐릭터 시트 · 제출 (STEP 4~5)
- 성격/강점/약점은 미리 준비된 선택지 또는 직접 입력 중 선택할 수 있습니다.
- 말풍선은 손잡이(⠿)를 드래그해서 위치를 옮기고, 텍스트 영역을 탭해서 글을 쓸 수 있습니다.
- "선생님에게 제출하기"는 기본적으로 학생 기기(브라우저)에 로컬 저장됩니다. 여러 기기의 제출물을 선생님이 한 곳에서 모아 보려면 `config.js`에 Cloudinary unsigned upload 정보(Stickman Class에서 쓰신 것과 동일한 방식)를 넣어주세요 — 그러면 자동으로 클라우드 업로드도 함께 시도합니다.
